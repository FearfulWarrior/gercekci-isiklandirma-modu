Gerçekçi Işıklandırma Modu — 0.1.1

Minecraft Java 1.20.1 + Forge 47.2.0.

İçerik: geleneksel ve modern floresanlar; merkezli ve bloktan küçük kare spot ve daire reflektör spot; geleneksel apartman plafonu (beyaz, soğuk beyaz, kirli sarı; dolu kapak); içi boş modern simit LED; yatay ve dikey şerit LED.

Kumanda tam RGB renk çarkı, 1000–10000 K Kelvin şeması, beş parlaklık seviyesi ve açma/kapama sağlar. RGB değeri blok verisinde saklanır ve ağ üzerinden aktarılır. Colorful Lighting'in auto örnekleme kuralı kullanılır.

LED merdiveni ve LED yuvalı tavan paneli bu düzeltme paketinde kaldırılmıştır. GitHub Actions Java 17 ile derleyip kaynak kontrollerini yapar; derlemenin başarılı olması oyun içi testin yerine geçmez.

Dağıtım sürümü ve JAR dosya adı bu çalışma boyunca 0.1.1 olarak korunmuştur. Otomatik derleme/varlık kontrolleri başarılıdır; son grafik ve performans kontrolü gerçek Minecraft istemcisinde yapılmalıdır.
